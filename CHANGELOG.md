# Istoric

## 1.1.1
- Limba se poate alege direct din aplicație: în meniul pictogramei, Limbă → Română, Español, English sau Limba sistemului, cu bifă pe alegerea curentă. Meniul trece imediat în limba aleasă, iar alegerea se păstrează; ferestrele deschise și dialogurile de sistem o preiau după „Redeschide acum”.

- Site nou, construit ca o scenă de desktop cu firul și demonstrația funcțională; README în română, spaniolă și engleză, cu imagini animate.
- Pregătită pentru GDC Plugin Manager (aplicație gratuită, macOS).

Capturile și ce copiezi stau pe sârmă, la un gest distanță.

Fiecare captură de ecran și tot ce copiezi se agață pe un fir chiar sub bara de meniu. Le cauți după conținut și le folosești cu gesturi directe. Gratuită, cu sursă deschisă, pentru Mac.

Doar în demonstrație: captura este o ilustrație generată, „clipboardul” este simulat, iar tragerea într-un folder și previzualizarea sunt imitate. În aplicație, tot ce se întâmplă rămâne pe Mac-ul tău.

Un gest pentru fiecare lucru

Clic
Copiază. O notă se copiază cu textul formatat.
Apăsare lungă
Deschide în Adnotare. O notă se deschide pentru editare.
Dublu clic
Deschide în Previzualizare. Un link se deschide în browser.
Tragere într-o aplicație
Trimite o copie; rămâne pe fir.
Tragere într-un folder
O păstrezi acolo; pleacă de pe fir.
Shift-clic
Selectezi mai multe; meniul, ⌘C, ⌫ și tragerea acționează asupra tuturor.
⌘Z pe fir
Anulează ce ai făcut: aruncare, fixare, salvare pe Desktop.
Clic dreapta
Partajează, fixează pe fir, ține în fața ferestrelor, arată în Finder.
⌃⌥T
Arată sau ascunde firul (se poate schimba).
⌃⌥F
Caută pe fir (se poate schimba).

Ce face

  • Capturi și înregistrări de ecran apar pe fir în clipa în care le faci, fără miniatura plutitoare și fără să se adune pe Desktop.
  • Ce copiezi: imagini, text și linkuri, cu opțiuni separate. Textul devine notă, linkul își arată site-ul.
  • Căutare în conținut: textul din capturi este citit local, pe Mac, iar căutarea ignoră diacriticele („sarma” găsește „sârmă”).
  • Privat: nu se păstrează nimic din câmpurile de parolă, din ce marchează ca privat un manager de parole sau din alt dispozitiv. Fără cont, fără rețea, fără statistici.

Dacă îi lași aplicației gestionarea capturilor, ea schimbă setările de captură din macOS (locația, miniatura plutitoare, destinația) și le pune la loc când o dezactivezi sau o închizi.
